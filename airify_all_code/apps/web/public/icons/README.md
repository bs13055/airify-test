# PWA Icons

Local placeholder PWA icons for the Airify demo.

- `icon-192.png` (192x192)
- `icon-512.png` (512x512)

These are simple locally generated placeholders (Airify blue with an "A"
monogram). No external or copyrighted assets are used. Replace with final
brand artwork before any public release.

Vite copies the contents of `public/` into `frontend/dist/` at build time, so
`/icons/icon-192.png` and `/icons/icon-512.png` are served by FastAPI from the
built frontend.
